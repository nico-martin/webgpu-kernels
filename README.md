# WebGPU Kernels Demo

Interactive demos for [`@huggingface/kernels`](https://www.npmjs.com/package/@huggingface/kernels), built with React, TypeScript, Vite, and Tailwind CSS.

## Run locally

```bash
pnpm install
pnpm dev
```

Open the local URL shown by Vite in a browser with WebGPU support.

## Build

```bash
pnpm build
```
